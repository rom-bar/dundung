# Asset sources

The following bundled asset is self-hosted so the game continues to render offline.

- **Press Start 2P** — designed by CodeMan38 / The Press Start 2P Project Authors. Source: [Google Fonts specimen](https://fonts.google.com/specimen/Press+Start+2P) and [Google Fonts repository folder](https://github.com/google/fonts/tree/main/ofl/pressstart2p). The font file is `public/fonts/PressStart2P-Regular.ttf`; the accompanying SIL Open Font License 1.1 text is preserved in `LICENSES/PressStart2P-OFL.txt`.

All game characters, pixel illustrations, icon designs, sounds, and source code are original to Pocket Pal.
